# M5.2-R3-P0 Teacher Pilot 实验报告

## 1. 当前结论

R3-P0 的配置、任务生成器、污染检查、Teacher 运行入口、严格 Trace 选择器、CPU 合成契约
Smoke、失败路径和真实 Qwen3-8B 实验已经完成。当前状态为
`COMPLETED_GATE_REJECTED`。

真实实验只接受 10/40 条，Config 和 Log Diagnosis 均未通过每类 14 条及 10/4 语言门禁。
正式 240 条来源扩展保持阻断；本结果不被改写为通过，也不用于启动 R3 训练。

## 2. 冻结实验

| 项目 | 固定值 |
| -- | -- |
| 输入任务 | Config 20 + Log Diagnosis 20 |
| 每类语言 | 英文 14 + 中文 6 |
| Teacher | `Qwen/Qwen3-8B@b968826d9c46dd6066d109eabc6255188de91218` |
| 模式 | 原生 Thinking、BF16、GQA、单卡 |
| 采样 | Temperature 0.6、Top-p 0.95、Top-k 20 |
| 候选数 | 每题最多 2 个 |
| 生成上限 | 384 New Tokens |
| Trace 上限 | 192 Token |
| 序列上限 | 1024 Token |

每类必须接受至少 14 条，其中英文至少 10 条、中文至少 4 条。接受 Trace 还必须满足答案
精确匹配、自然闭合、Repeated 8-gram 不超过 5%、无重复行、全局 Trace 唯一和完整序列不
超过 1024 Token。

## 3. 真实实验结果

| 任务族 | 输入 | 接受 | 英文接受 | 中文接受 | Trace Token Min/P50/P90/Max | 门禁 |
| -- | --: | --: | --: | --: | -- | -- |
| Config | 20 | 5 | 4 | 1 | 127 / 145 / 181 / 181 | 拒绝 |
| Log Diagnosis | 20 | 5 | 5 | 0 | 164 / 183 / 188 / 188 | 拒绝 |
| 合计 | 40 | 10 | 9 | 1 | — | 拒绝 |

80 个候选全部完成生成。选择器审计了 73 个候选；7 个候选因同题候选 0 已通过而不再消费。
审计结果为：

| 结果 | 数量 | 说明 |
| -- | --: | -- |
| 接受 | 10 | 格式、答案、长度、重复与污染全部通过 |
| 推理超过 192 Token | 52 | 主要失败原因 |
| 触及 384 Token 生成上限 | 11 | 不接受截断输出 |

没有出现 Final JSON、答案匹配、重复行、重复 Trace 或 8-gram 超限拒绝。失败集中在原生
Thinking 长度控制，而不是任务答案契约。英文任务接受 9/28，中文只接受 1/12；中文
Log Diagnosis 为 0/6，是下一轮必须单独验证的风险分层。

标签分布也不均衡：英文 Config 的 `missing_checkpoint` 为 3/3，而
`forbidden_truncation` 和 `unsupported_precision` 均为 0；英文 Log 的 `cuda_oom` 与
`disk_full` 各接受 2 条，`collective_timeout` 为 0。该差异不用于放宽门禁。

## 4. 前置验证与环境失败

固定任务集共 40 条，任务集 SHA256 为：

```text
cf0fee91d2a3362cb3fd6567485b12596d278bac889fcfc8abc8453acc337f2f
```

与 200 条冻结 Reasoning Dev 和 100 条历史 Pilot 的 Exact Prompt、规范化 Prompt 及
Template Family 污染计数均为 0。CPU 合成契约 Smoke 验证了 40 条任务可通过完整构建流程；
该 Smoke 明确标记为 `model_generated=false`、`quality_metric=false`、`gpu_used=false`。

失败路径已经覆盖：

- Teacher 未闭合 Thinking；
- Final JSON 答案错误；
- 生成触及长度上限；
- 推理超过 192 Token；
- 重复规范化 Trace；
- 重复非空行；
- 完整序列超过 1024 Token；
- Dev 或历史 Pilot 污染。

首次自动启动在模型加载前被版本校验拒绝：Teacher 环境提供 `tokenizers=0.22.2`，而冻结
Qwen3-0.6B Tokenizer 契约要求 `0.21.4`。运行器因此拆分为两个隔离阶段：

1. `.venv-baseline` 只执行 Qwen3-8B 生成并保存私有候选；
2. `.venv` 使用冻结的 `tokenizers=0.21.4` 完成 Token 计数、Trace 选择、Gate 和公开汇总。

该调整没有安装、降级或绕过依赖校验，并在公开结果中分别记录 Teacher 与 Policy
Tokenizer 版本。

Preflight。Raw Output、逐候选审计和逐条 Verifier 只写入私有 Artifact；公开 JSON 只保存
聚合计数、哈希、版本、硬件、时长和显存。

## 6. 下一步决策

P0 未通过，因此不进入每类 120 条、合计 240 条的正式扩展。下一批先冻结 P0-R1 Prompt
控制诊断：

1. 使用新的 Task ID、Template Family、Config Hash 和 Sampling Seed；
2. 把宽泛的“简洁推理”改为“先给结论，再用一个直接证据说明，不枚举备选项”的双语结构；
3. 保持 Qwen3-8B、原生 Thinking、0.6/0.95/20 采样、两个候选、192 Token Trace 上限、
   384 Token 生成上限和污染检查全部不变；
4. 使用同样的分层门禁验证 Config/Log 及英文/中文覆盖；
5. 若仍失败，则记录当前 Teacher/Prompt 组合不适合作为 R3 简洁 Trace 来源，不继续消耗
   240 任务生成预算。

这一决策不读取 M6 冻结评测，也不降低任何质量阈值。

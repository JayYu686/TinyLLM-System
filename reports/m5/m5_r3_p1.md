## 3. 已实现链路

```text
40 个新任务
→ Dev / 历史 Pilot / P0 / P0-R1 污染检查
→ Thinking Solver
→ Solver Final JSON Exact Verify
→ Non-thinking Compressor
→ 严格 JSON Envelope
→ Compressor Final JSON Exact Verify
→ Evidence Anchor / 其他标签 / 长度 / 重复 / 唯一性检查
→ Qwen3 Thinking 训练序列渲染
→ 14/10/4 来源 Gate
```

Solver 未正确闭合或答案错误时不会调用 Compressor。Compressor 的输出独立验证，不继承
Solver 的通过状态。所有原始 Task、Solver 推理和 Compressor 输出只进入私有 Artifact；
公开结果只保留哈希、计数、长度与拒绝原因。

## 6. 结论与下一步

P1 的主要问题已经收敛为两类：

1. Solver 在 6 条 Config 任务达到 896 Token 上限，使英文 Config 的理论最大接受数只有 9，
   无法达到英文至少 10 条；
2. Compressor 看到了原任务中的全部标签和冗长 Solver 枚举，导致 20 条输出遗漏原文证据
   锚点或讨论其他标签。

下一项有界实验使用新身份：仅在首个 Solver 答案不合格时生成第二候选；Compressor 只接收已经
验证的答案、原文证据和锚点，不再接收其他标签或完整 Solver 枚举。192 Token、14/10/4、
污染和后续 99% 门禁全部保持不变。该实验通过前继续禁止正式扩展和训练。

# M5.2-R3-P2 Solver 回退与 Compressor 隔离实验报告

## 1. 结论

P1 真实运行接受 11/40 条后，P2 只修复已经观察到的两类失败：

1. 6 条 Solver 达到 896 Token 上限；
2. Compressor 因看到全部候选标签和冗长 Solver 推理，产生 10 条证据锚点缺失、
   10 条其他标签提及和 3 条非严格 JSON。

`m5-r3-p2-fallback-isolated-v1` 已在单张 RTX 3090 上完成真实 Qwen3-8B Pilot，
接受 33/40 条：Config 17/20、Log Diagnosis 16/20，两个任务族均满足 14/10/4 门禁，
四路污染检查为 0。当前状态为 `COMPLETED_GATE_PASSED`。

CPU Smoke 的 40/40 是合成契约结果，`model_generated=false`、`quality_metric=false`；
真实 GPU 结果独立记录。该结果只授权人工内容审查与正式 240 条来源扩展，Mixture 和训练
仍保持阻断。

## 3. 最小变量

P2 不重跑已通过答案验证的 34 个 P1 Solver。执行链路为：

```text
校验 P1 Public Result 与私有 Generation SHA
→ 重建 40 个 P1 Solver
→ 仅为 6 个失败 Solver 生成第二候选
→ 选择首个通过 Exact Answer Verify 的 Solver
→ Compressor 只读取已验证答案、原始证据和 Evidence Anchor
→ 冻结 Tokenizer 执行 Trace Policy
→ 原 14/10/4 Gate
```

第二 Solver 仍使用 Thinking、最大 896 Token、Temperature 0.6、Top-p 0.95、Top-k 20。
Compressor 仍使用 Non-thinking 贪心解码和最大 256 Token。它不再接收原始 Solver 推理，
也看不到未选标签。

## 4. 未改变的门禁

- Config / Log Diagnosis 每类至少接受 14/20；
- 每类英文至少 10 条、中文至少 4 条；
- 可见推理不超过 192 Token；
- Repeated 8-gram Ratio 不超过 5%；
- 必须包含原文 Evidence Anchor；
- 禁止提及其他标签；
- 完整训练序列不超过 1024 Token；
- 四路污染必须为 0；
- 规则 Trace 继续只作 `control_only`；
- 后续 Thinking 格式率仍要求两个 Seed 均至少 99%。

P2 真实通过只允许人工内容审查与正式来源扩展，不能直接授权 Mixture 或训练。
